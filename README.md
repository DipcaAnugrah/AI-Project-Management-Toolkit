# 🧠 AI Project Management Toolkit

Toolkit manajemen proyek Artificial Intelligence berbasis metodologi **CRISP-DM** yang dirancang untuk membantu tim dalam merencanakan, menjalankan, dan mengevaluasi proyek AI secara sistematis, terstruktur, dan profesional.

Toolkit ini dikembangkan sebagai **Final Project Mata Kuliah Artificial Intelligence** Universitas Pelita Bangsa.

---

## 🚀 Fitur Utama

- 📘 **Panduan CRISP-DM AI**  
  Panduan operasional pengelolaan proyek AI dari awal hingga deployment.

- 📝 **Template Proyek AI**  
  Dokumen kerja untuk mendokumentasikan seluruh proses proyek AI.

- 📊 **RACI Matrix**  
  Alat pembagian peran dan tanggung jawab tim proyek.

- ⚠️ **Risk Register**  
  Manajemen risiko proyek AI secara sistematis.

- ✅ **Checklist Kesiapan AI**  
  Evaluasi kesiapan proyek sebelum implementasi dan deployment.

## 🛠️ Cara Menggunakan Toolkit

1. Baca **01_Panduan_CRISP_DM_AI.pdf** untuk memahami alur proyek.
2. Isi **02_Template_Project_AI.docx** sebagai dokumentasi proyek.
3. Gunakan **03_RACI_Matrix.xlsx** untuk pembagian tugas.
4. Kelola risiko melalui **04_Risk_Register.xlsx**.
5. Evaluasi kesiapan menggunakan **05_Checklist_Kesiapan_AI.xlsx** sebelum deployment.
